# Edge-FML 算法流程总结

本文档总结了 Edge-FML (Edge Federated Membrane Learning) 系统中各个核心组件及支持模块的具体算法流程。

## 1. 核心框架 (Core Framework)

### 1.1 `EdgeFML.m` (基础框架)
实现了基于膜计算的联邦学习四阶段协同优化框架。

**主要流程:**
1.  **初始化 (Initialization):**
    *   加载区域配置 (`RegionConfig`) 和任务数据 (`TaskData`)。
    *   初始化全局模型和各区域的本地优化器 (`MTDMS_CMOEA_Local`)。
    *   初始化聚类管理器 (`ClusterManager`)。
2.  **联邦循环 (Federated Loop) - 共 `R_max` 轮:**
    *   **阶段 1: 本地进化 (Local Evolution):**
        *   每个区域并行执行 `M_local` 代的本地多目标优化。
        *   输出：本地种群及其帕累托前沿。
    *   **阶段 2: 聚类交换 (Cluster Exchange):**
        *   计算区域间的异质性差异 (`Dissimilarity Matrix`)。
        *   执行谱聚类 (`Spectral Clustering`) 将区域分组。
        *   在簇内选择代表性解（基于拥挤距离和收敛性）。
        *   在簇内区域间交换代表性解（膜通信）。
    *   **阶段 3: 联邦聚合 (Federated Aggregation):**
        *   收集各簇的优秀解。
        *   使用全局聚合策略（如加权平均或非支配排序合并）生成全局指导解。
        *   将全局指导解广播回所有区域。
    *   **阶段 4: 本地集成 (Local Integration):**
        *   各区域接收全局指导解。
        *   将指导解注入本地种群（替换最差解或作为精英保留）。
        *   执行环境选择以维持种群多样性。
3.  **收敛检查与终止 (Termination):**
    *   检查是否达到最大轮数或收敛标准。
    *   输出最终的帕累托解集。

### 1.2 `EdgeFML_Enhanced.m` (增强版框架)
在基础框架之上增加了健壮性机制。

**主要流程差异:**
*   **异常处理:** 在每个阶段（本地进化、通信）包裹 `try-catch` 块，防止单个节点的失败导致整个训练崩溃。
*   **资源监控:** 实时监控内存和计算资源使用情况，动态调整种群大小或进化代数以适应受限环境。
*   **自适应参数:** 根据当前的收敛速度动态调整交叉概率 (`CR`) 和变异因子 (`F`)。

### 1.3 `EdgeFML_Parallel.m` (并行版框架)
利用 MATLAB 的并行计算工具箱加速优化过程。

**主要流程差异:**
*   **并行本地进化:** 使用 `parfor` 替代 `for` 循环，同时在多个 Worker 上执行不同区域的 `Local Evolution`。
*   **并行评估:** 在目标函数评估 (`ObjectiveEvaluator`) 阶段使用并行计算，加速耗时的模拟或计算过程。
*   **数据同步:** 增加了显式的数据同步点，确保并行任务完成后再进行联邦聚合。

## 2. 局部优化算法 (Local Optimization)

### 2.1 `MTDMS_CMOEA_Local.m` (串行局部优化器)
基于多任务动态多群约束多目标进化算法。

**主要流程:**
1.  **种群初始化:** 随机生成决策变量（卸载决策 `x`, 缓存决策 `y`, 资源分配 `f`, 安全等级 `z`）。
2.  **修复策略 (Repair):** 强制满足基本约束（如缓存容量限制、资源总量限制）。
3.  **多膜协同进化 (Multi-Membrane Co-evolution):**
    *   将种群分为多个膜（子种群），每个膜侧重不同的搜索策略（如收敛性优先、多样性优先）。
    *   **阶段 1 (快速收敛):** 使用差分进化 (DE) 算子快速逼近帕累托前沿。
    *   **阶段 2 (约束处理):** 引入自适应阈值 (`epsilon-constraint`) 处理约束，允许适度违反约束的解生存。
4.  **环境选择 (Environmental Selection):**
    *   基于非支配排序 (Non-dominated Sorting) 和拥挤距离 (Crowding Distance) 筛选下一代。
5.  **输出:** 返回进化后的种群和非支配解集。

### 2.2 `PAR_MTDMS_CMOEA.m` (并行局部优化器)
`MTDMS_CMOEA_Local` 的并行实现版本。

**主要流程差异:**
*   **膜并行:** 不同的膜（子种群）在不同的线程/核心上独立进化。
*   **评估并行:** 种群中个体的适应度评估并行化。
*   **通信:** 膜之间定期交换精英个体（迁移操作）。

## 3. 关键组件 (Key Components)

### 3.1 `ClusterManager.m` (聚类管理器)
负责处理区域的异质性分组。

**主要流程:**
1.  **计算相异度矩阵 (Dissimilarity Matrix):**
    *   基于计算能力、缓存大小、带宽、设备数量等特征，计算两两区域间的距离。
    *   公式: `RD(r, l) = 1/4 * sum(relative_diff_metrics)`。
2.  **谱聚类 (Spectral Clustering):**
    *   构建拉普拉斯矩阵 (`Laplacian Matrix`)。
    *   计算特征值和特征向量。
    *   使用 K-Means 对特征向量空间进行聚类。
3.  **簇代表选择:**
    *   在每个簇中，选择综合性能最强（或处于中心位置）的区域作为簇头 (Cluster Head)。

### 3.2 `DiversityEnhancer.m` (多样性增强器)
防止算法早熟收敛，维持种群分布。

**主要流程:**
1.  **拥挤距离计算:** 计算同一帕累托前沿上个体间的密度。
2.  **小生境技术 (Niche Selection):**
    *   识别拥挤区域。
    *   惩罚拥挤区域内的个体适应度，增加稀疏区域个体的生存概率。
3.  **随机移民 (Random Immigrants):**
    *   每隔固定代数，随机引入新生成的个体替换种群中最差的个体。

### 3.3 `ObjectiveEvaluator.m` (目标评估器)
计算个体的目标函数值和约束违反度。

**主要流程:**
1.  **输入解析:** 获取个体的决策变量 (x, y, f, z)。
2.  **目标计算 (Objectives):**
    *   **时延 (Latency):** 本地计算时间 + 传输时间 + 边缘执行时间。
    *   **能耗 (Energy):** 传输能耗 + 计算能耗 + 待机能耗。
    *   **安全风险 (Risk):** 基于任务安全等级和设备信任度的匹配程度计算风险值。
3.  **约束检查 (Constraints):**
    *   计算超出缓存容量、最大时延、资源限制的程度。
    *   汇总所有违反量为单一的 `ConstraintViolation` 值。

### 3.4 `PerformanceMetrics.m` (性能指标)
评估算法结果的质量。

**主要流程:**
1.  **超体积 (Hypervolume, HV):** 计算解集在目标空间覆盖的体积（相对于参考点）。
2.  **可行性率 (Feasibility Rate):** 统计最终解集中满足所有约束的个体比例。
3.  **多样性 (IGD/Spacing):** 计算解在帕累托前沿上的分布均匀性。

### 3.5 `InputValidator.m` (输入验证器)
确保系统输入的合法性和完整性。

**主要流程:**
1.  **类型检查:** 验证输入是否为预期的类实例（如 `RegionConfig`, `TaskData`）。
2.  **范围检查:** 检查数值参数（如带宽、功率）是否在物理合理的范围内。
3.  **一致性检查:** 确保区域数量与任务集数量匹配。
4.  **资源预估:** 根据输入规模估算所需内存，若超过系统限制则发出警告。

### 3.6 `RegionConfig.m` (区域配置)
定义边缘区域的属性。

**主要流程:**
*   **属性存储:** 存储 `computeCapacity`, `cacheCapacity`, `bandwidth` 等。
*   **辅助计算:** 提供 `computeDissimilarity` 方法供 `ClusterManager` 调用。

## 4. 报告与可视化 (Reporting & Visualization)

### 4.1 `EdgeFMLLogger.m` (日志记录器)
记录运行时信息。

**主要流程:**
1.  **初始化:** 创建日志文件，设置日志级别（INFO, DEBUG, ERROR）。
2.  **记录:** 接收消息，添加时间戳，写入文件并（可选）打印到控制台。
3.  **性能追踪:** 记录每轮的 HV 值、通信开销等，用于后续绘图。

### 4.2 `ReportGenerator.m` (报告生成器)
生成实验总结报告。

**主要流程:**
1.  **数据收集:** 汇总 `EdgeFMLLogger` 和 `PerformanceMetrics` 产生的数据。
2.  **内容编排:** 按照模板（摘要、参数设置、性能对比、结论）组织内容。
3.  **格式输出:** 调用转换函数生成 HTML, PDF 或 Markdown 格式的报告文件。

### 4.3 `AdvancedVisualization.m` (高级可视化)
生成专业的图表。

**主要流程:**
1.  **帕累托前沿绘制:**
    *   绘制 3D 散点图 (Latency, Energy, Risk)。
    *   标记非支配解。
2.  **收敛曲线绘制:** 绘制 HV 随迭代轮数的变化曲线。
3.  **统计图表:** 生成箱线图 (Boxplot) 展示多次运行的稳定性。
4.  **保存:** 将图表导出为高分辨率图片 (PNG/PDF)。
