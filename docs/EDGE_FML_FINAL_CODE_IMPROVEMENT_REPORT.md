## 使用指南

### 1. 快速开始
```matlab
% 1. 部署系统
deploy_edge_fml();

% 2. 添加路径
addpath('./EdgeFML_Deployed/src');

% 3. 生成测试数据
regions = SimulationDataGenerator.generateRegions(5);
taskSets = SimulationDataGenerator.generateTaskSets(regions);

% 4. 运行Edge-FML
edge_fml = EdgeFML(regions, taskSets, 20, 50);
edge_fml.run();
```

### 2. 高级配置
```matlab
% 自定义配置
config = struct();
config.system.max_regions = 100;
config.system.max_rounds = 200;
config.logging.level = 'DEBUG';
config.performance.enable_profiling = true;

% 保存配置
save('./EdgeFML_Deployed/config/custom_config.mat', 'config');
```

### 3. 调试和监控
```matlab
% 启用调试模式
logger = EdgeFMLLogger.getInstance('./logs/', EdgeFMLLogger.DEBUG);
logger.enableDebugMode(true);

% 性能监控
logger.startTimer('total_training');
% ... 训练代码 ...
elapsed = logger.stopTimer('total_training');
```
