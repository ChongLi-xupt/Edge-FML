# Edge-FML：面向边缘计算分布式多目标优化的联邦膜学习算法

## 摘要

针对边缘计算环境中分布式多目标优化面临的数据隐私保护、通信瓶颈和区域异质性三大挑战，本文提出边缘联邦膜学习算法（Edge-FML）。该算法将生物启发的膜计算范式与联邦学习框架深度融合，构建了三层联邦膜结构——区域层、集群层和联邦层。在区域层，每个边缘区域作为一个独立膜，运行多任务动态膜计算约束多目标进化算法（MTDMS-CMOEA-Local），通过差分进化变异、约束修复型变异和增强拥挤距离环境选择实现膜内进化；在集群层，相似区域通过谱聚类形成集群，实现集群内高效知识交换；在联邦层，集群代表通过自适应阈值Shamir秘密共享实现加密的全局知识聚合。本文重点阐述了膜计算中膜选择、交叉操作、变异规则和膜溶解条件在Edge-FML中的具体实现，以及这些膜操作与多目标约束处理策略的深度协同机制。

**关键词**：膜计算；联邦学习；多目标优化；约束处理；边缘计算；差分进化

## 一、引言

随着物联网设备数量呈指数级增长，边缘计算成为解决海量数据处理需求的关键范式。然而，集中式优化方法面临三个根本性挑战：（1）数据隐私问题，边缘设备产生的任务特征和资源使用模式构成高度敏感信息；（2）通信瓶颈，当边缘节点数量达到数百甚至数千时，全量数据上传导致通信开销呈O(N²)增长；（3）区域异质性，不同地理区域的边缘节点具有显著差异化的硬件配置、网络条件和工作负载特性。

传统联邦学习方案虽能保护原始数据隐私，但在多目标优化场景下面临独特挑战：解空间的高度非凸性、约束条件的区域特异性，以及Pareto前沿在异构环境中的不一致性，导致标准的模型/梯度聚合策略失效。针对上述挑战，本文提出Edge-FML——一个将膜计算与联邦学习深度融合的分布式多目标优化框架。

膜计算（Membrane Computing）是受生物细胞膜结构和功能启发而提出的自然计算范式，其核心思想是将计算单元划分为多个并行运作的"膜"，每个膜内部独立执行进化规则，膜之间通过选择性物质交换实现协同进化。这种分布式、并行化、层次化的计算模型天然契合边缘计算的去中心化架构需求。

## 二、问题形式化

### 2.1 系统模型

考虑由N个地理分布的边缘区域组成的系统，每个区域r具有异构特性：计算能力F_r、缓存容量C_r^max、设备数量K_r、网络带宽B_r。区域r的本地决策变量定义为：

$$\mathbf{x}_r = \left( \{x_{r,k}\}_{k=1}^{K_r}, \{y_{r,t}\}_{t=1}^T, \{f_{r,t}\}_{t=1}^T, \{z_{r,k}\}_{k=1}^{K_r} \right)$$

其中x_{r,k}∈{0,1}为任务卸载决策，y_{r,t}∈{0,1}为缓存策略，f_{r,t}≥0为资源分配比例，z_{r,k}∈{1,2,3,4}为安全等级。

### 2.2 多目标优化模型

区域r的本地优化问题为三目标约束优化：

$$\min \mathbf{f}_r(\mathbf{x}_r) = \left( T_r^{\text{total}}(\mathbf{x}_r), E_r^{\text{total}}(\mathbf{x}_r), \Psi_r(\mathbf{x}_r) \right)$$

$$\text{s.t.} \quad g_{r,j}(\mathbf{x}_r) \leq 0, \quad j = 1,2,3,4$$

其中三个目标函数分别为总时延T_total、总能耗E_total和安全风险Ψ。四类硬约束为：

- **g1（计算容量约束）**：$\sum f_{r,t} \leq T$，总资源分配不超过计算容量
- **g2（缓存限制约束）**：$\sum y_{r,t} \cdot D_t \leq C_r^{\max}$，缓存数据总量不超过缓存容量
- **g3（截止时间约束）**：$T_{r,k}^{\text{total}} \leq D_{\tau(r,k)}^{\text{dl}}$，卸载任务总时延不超过截止时间
- **g4（安全合规约束）**：$z_{r,k} \geq s_{\tau(r,k)}^{\min}$，安全等级不低于任务最低要求

总约束违反度定义为：$CV_r(\mathbf{x}_r) = \sum_{j=1}^{4} \max(0, g_{r,j}(\mathbf{x}_r))$。

## 三、Edge-FML算法设计

### 3.1 三层联邦膜结构

Edge-FML采用三层联邦膜结构，将膜计算的层次化并行特性与联邦学习的分布式架构有机结合：

**第一层——区域层（Regional Layer）**：每个边缘区域作为一个独立的"膜"，运行MTDMS-CMOEA-Local本地膜优化器。膜内独立执行差分进化、环境选择和精英存档，无需与外部通信即可完成本地Pareto前沿的搜索。该层对应膜计算中的"膜内并行进化"。

**第二层——集群层（Cluster Layer）**：基于区域异质性度量（Region Dissimilarity, RD），通过谱聚类将相似区域划分为M个集群。集群内区域直接交换精英解（未加密），实现高效的局部知识共享。该层对应膜计算中的"膜间物质交换"。

**第三层——联邦层（Federated Layer）**：各集群代表节点通过自适应阈值Shamir秘密共享（AT-SSS）加密交换全局知识。该层确保跨集群协调的同时保护区域隐私，对应膜计算中的"选择性渗透"。

主算法框架如算法1所示。

**算法1：Edge-FML主框架**

```
输入：N个区域配置，R_max最大联邦轮数，M_local本地进化代数
输出：全局Pareto前沿近似S_global

1.  初始化：为每个区域r并行初始化MTDMS-CMOEA-Local种群
2.  运行谱聚类算法形成集群{C_1, ..., C_M}
3.  为每个集群选举代表节点R_m

4.  for round = 1 to R_max do
5.      // 阶段1：本地膜进化
6.      for each region r in parallel do
7.          S_r ← MTDMS-CMOEA-Local(r, M_local)
8.          E_r ← 选择精英解(S_r, M_elite)
9.          v_r ← 计算平均约束违反度(E_r)
10.     end for
11.
12.     // 阶段2：集群级知识交换
13.     for each cluster C_m in parallel do
14.         集群内广播精英解{E_r}和约束违反度{v_r}
15.         集群代表聚合：E_{C_m} ← MergeAndFilter({E_r}, 0.6)
16.         v_{C_m} ← 平均约束违反度
17.     end for
18.
19.     // 阶段3：联邦知识聚合（加密）
20.     全局协调器接收{E_{C_m}, v_{C_m}}
21.     v_global ← AT-SSS加密聚合({v_{C_m}})
22.     E_global ← 基于HV贡献选择全局精英解
23.
24.     // 阶段4：本地知识集成
25.     for each region r in parallel do
26.         E_adapted ← SolutionAdapter(E_global, r)
27.         S_r ← MergeAndSelect(S_r, E_adapted)
28.     end for
29. end for
30.
31. return 全局非支配排序(∪_r S_r)
```

### 3.2 MTDMS-CMOEA-Local：本地膜计算优化器

MTDMS-CMOEA-Local是Edge-FML区域层的核心膜优化器，其设计融合了膜计算的核心操作——膜内进化、膜选择和膜溶解。该优化器维护一个自适应大小的种群（膜内对象集合），通过差分进化生成新个体（膜内反应），通过环境选择淘汰劣质个体（膜溶解），最终输出精英存档（膜产物）。

#### 3.2.1 自适应种群初始化

种群大小根据区域设备数量自适应调整：

$$N_{\text{pop}}(r) = N_{\text{base}} \cdot \left(1 + 0.5 \cdot \frac{K_r - K^{\min}}{K^{\max} - K^{\min}}\right)$$

其中N_base=100，K_min=20，K_max=100，N_pop限制在[50, 200]范围内。高负载区域分配更大的膜内种群以提升搜索能力，低负载区域使用较小的种群以节约计算资源，体现了膜计算中的资源自适应分配思想。

每个个体（Solution）包含四类决策变量：x_offload（卸载决策，K维二进制向量）、y_cache（缓存策略，T维二进制向量）、f_resource（资源分配，T维连续向量，取值[0.1, 1.0]）、z_security（安全等级，K维整数向量，取值{1,2,3,4}）。初始化采用保守策略：30%概率卸载、10%概率缓存、资源分配[0.1, 0.5]、安全等级[2, 4]，以降低初始约束违反度。

#### 3.2.2 膜进化主循环

每代进化包含五个步骤，对应膜计算中的完整生命周期：

```
for gen = 1 to maxGen do
    步骤1：更新动态约束阈值（膜溶解条件更新）
    步骤2：通过交叉+变异+修复生成子代（膜内反应）
    步骤3：合并父代和子代（膜内物质积累）
    步骤4：环境选择（膜选择与膜溶解）
    步骤5：更新精英存档（膜产物提取）
end for
```

## 四、膜计算核心操作

### 4.1 膜选择机制

膜选择机制决定了哪些个体在膜内存活并进入下一代。Edge-FML实现了基于**约束支配 + 增强拥挤距离**的双层选择策略，该策略是膜计算选择性渗透特性在算法层面的具体实现。

#### 4.1.1 基于动态阈值的可行性分区

环境选择的第一阶段是将合并种群按约束违反度与动态阈值θ_T比较，分为"当前可行"和"当前不可行"两个子集：

$$\mathcal{F}_{\text{feasible}} = \{i \mid CV(\mathbf{x}_i) \leq \theta_T\}$$

$$\mathcal{F}_{\text{infeasible}} = \{i \mid CV(\mathbf{x}_i) > \theta_T\}$$

其中θ_T为动态约束阈值，随进化代数动态衰减。这一分区机制模拟了生物膜对物质的选择性通透——只有满足当前阈值条件的个体才能进入可行池。

#### 4.1.2 非支配排序与拥挤距离选择

对可行个体执行非支配排序，按Pareto等级和增强拥挤距离进行排序选择。Edge-FML的增强拥挤距离计算融合了传统拥挤距离和k近邻小生境多样性奖励：

$$d_{\text{crowd}}(i) = \sum_{m=1}^{M} \frac{f_m(i+1) - f_m(i-1)}{f_m^{\max} - f_m^{\min}} + \frac{1}{k}\sum_{j=1}^{k} \|\mathbf{f}(i) - \mathbf{f}(\text{NN}_j(i))\|\cdot 0.5$$

其中第一项为传统拥挤距离，第二项为k近邻（k=3）平均距离的0.5倍作为小生境奖励。该机制使得膜选择时既考虑目标空间分布均匀性，又奖励位于稀疏区域的个体，有效防止膜内种群的早熟收敛。

#### 4.1.3 不可行解的补充选择

当可行解数量不足时，按约束违反度从小到大从不可行池中补充个体。该策略确保在进化早期（可行解稀缺时）种群规模不缩减，同时优先选择最接近可行域的个体，维持向可行域收敛的压力。

### 4.2 交叉操作与变异规则

Edge-FML的交叉变异操作对应膜计算中的"膜内进化规则"——膜内分子通过随机碰撞和重组产生新物质。

#### 4.2.1 差分进化交叉（DE/rand/1）

对连续变量（资源分配f_resource）采用标准DE/rand/1策略。随机选取三个父代个体x1、x2、x3，以变异因子F=0.5和交叉率CR=0.35执行操作：

$$\text{trial}_t = \begin{cases} x_{1,t} + F \cdot (x_{2,t} - x_{3,t}) & \text{if } rand < CR \\ x_{\text{parent},t} & \text{otherwise} \end{cases}$$

变异后的值被裁剪至[0.1, 1.0]范围内。DE/rand/1策略具有高探索性，能够跨越不可行区域，在广阔搜索空间中寻找潜在的可行区域。

#### 4.2.2 三父代二进制交叉

对离散变量采用三父代差异化交叉策略——卸载决策x_offload来自父代x1，安全等级z_security来自父代x2，缓存策略y_cache来自父代x3。每维以交叉率CR=0.35独立决定是否继承对应父代的值，否则保留当前父代的值。这种差异化交叉策略允许不同类型的决策变量从不同的"知识源"独立获取信息，增加了搜索的多样性。

#### 4.2.3 约束修复型变异

交叉后对子代执行三类约束驱动的修复变异，对应膜计算中"膜的自我修复"能力：

**安全等级修复（g4约束）**：对每个卸载任务，将其安全等级强制提升至不低于任务最低要求——
$$z_{r,k} \leftarrow \max(z_{r,k}, s_{\tau(r,k)}^{\min}), \quad \forall k: x_{r,k}=1$$

**资源分配缩放（g1约束）**：当总资源分配超出计算容量时，等比缩放至可行域内并保留5%安全余量——
$$\mathbf{f} \leftarrow \mathbf{f} \cdot \frac{T \cdot 0.95}{\sum_t f_t}, \quad \text{if } \sum_t f_t > T$$

**缓存溢出修复（g2约束）**：当缓存总数据量超出容量时，按数据大小降序贪婪地取消大体积任务的缓存，直至满足容量限制。

### 4.3 膜溶解条件与触发机制

在膜计算范式中，"膜溶解"对应种群中劣质个体被淘汰的过程。Edge-FML实现了多层级的膜溶解机制，从不同粒度控制解的质量。

#### 4.3.1 动态阈值驱动的膜溶解

这是Edge-FML最核心的膜溶解机制，其动态阈值公式为：

$$\theta_r(t) = \theta_0 \cdot \left(1 - \frac{\log(t+1)}{\log(T_{\max}+1)}\right) \cdot e^{-\lambda \cdot \text{ResourceUtil}_r}$$

其中θ_0=2.0为初始阈值，λ=0.8为资源利用率衰减因子。该公式由三个因子复合而成：

- **时间衰减因子** timeFactor = 1 - log(t+1)/log(T_max+1)：对数衰减，从1逐步降至0，使约束阈值随进化进程自然收紧。
- **资源利用率因子** loadFactor = e^{-λ·ResourceUtil}：ResourceUtil越大（区域负载越高），阈值越低，约束越严格，加速向低资源消耗方向收敛。
- **初始阈值** θ_0 = 2.0：提供宽松的初始约束容忍度，允许早期探索跨越不可行区域。

该动态阈值在每个个体的约束违反度CV≤θ_T时判定为"当前可行"，否则在环境选择中被淘汰。随着进化进程，θ_T从2.0逐步衰减至接近0，实现从宽松到严格的渐进式收紧：

- **早期（t小）**：θ_T较大，允许高CV个体存活，维持探索多样性，跨越不可行区域发现潜在可行区
- **后期（t大）**：θ_T趋近于0，仅保留CV≈0的个体，确保最终解的严格可行性
- **高负载区域**：loadFactor更低，约束更严格，加速向低资源消耗方向收敛

#### 4.3.2 精英存档的严格可行过滤

精英存档采用严格的可行过滤标准（CV ≤ 10⁻⁶），仅保留严格满足所有约束的非支配解。当无可行解时，采用退化策略保留约束违反度最小的个体。这一机制确保膜输出的精英解具有实际部署的可行性。

#### 4.3.3 联邦层知识过滤溶解

在联邦训练的四个阶段中，知识交换同样包含多层过滤溶解：

- **集群内过滤**：仅保留CV≤0.05的精英解，经多样性预筛选后再合并过滤
- **联邦聚合过滤**：自适应阈值θ_agg = 0.05 × 0.99^(round-1)，仅广播违反度超过阈值的约束维度
- **全局精英选择**：基于超体积（HV）边际贡献排序，选择对全局前沿贡献最大的精英解

## 五、膜间知识交换与兼容性机制

### 5.1 集群级膜间知识交换

集群内的膜之间直接进行精英解广播（未加密），每个区域收集集群内其他区域的精英解后，由集群代表进行合并过滤。这种设计利用了集群内区域高度相似（平均RD < 0.2）的特性，使得解在集群内直接迁移的可行性较高。

### 5.2 联邦知识聚合与加密通信

联邦层通过自适应阈值Shamir秘密共享（AT-SSS）实现加密的集群间知识交换。Shamir(t,n)方案将秘密s分割为n个份额，任何t个或更多份额可重构s，任何t-1个或更少份额不泄露任何信息（信息论安全）。自适应阈值根据轮数衰减：θ_agg = 0.05 × 0.99^(round-1)，随训练轮数增加逐步降低广播阈值，从保守向积极过渡。

### 5.3 跨膜解兼容性适配

外部膜的精英解不能直接注入目标膜，需要通过SolutionAdapter进行三阶段兼容性处理：

**阶段一：参数归一化**。将外部解映射到目标膜参数空间，执行四项映射：（1）资源映射：f_target = f_source × capacityRatio，按计算能力比例缩放；（2）缓存适配：仅在目标膜容量允许时保留缓存决策；（3）卸载决策映射：按设备索引循环映射；（4）安全等级校准：高异质性区域（RD > 0.5）或高安全需求任务保守提升安全等级。

**阶段二：可行域映射**。对归一化解进行局部修复优化，包括计算过载修复（降低非关键任务资源）、缓存溢出修复（移除低优先级缓存）、截止时间修复（增加高优先级任务资源）和安全合规修复，并辅以10代梯度引导微调局部搜索。

**阶段三：兼容性评分**。兼容性评分公式为：

$$\text{Compat}(r,l,\mathbf{s}) = e^{-\beta \cdot \text{RD}(r,l)} \cdot (1 - CV_r(\mathbf{s}_{\text{norm}})) \cdot I_l(\mathbf{s})$$

其中β=2.0为异质性衰减系数，RD(r,l)为区域差异度，CV_r为归一化后解的约束违反度，I_l(s)为解在源区域的重要性。三个因子分别从异质性衰减、本地可行性和源区域重要性三个维度评估外部解与目标膜的兼容程度。仅当Compat > θ_keep=0.35时保留外部解，否则该解被膜溶解。

## 六、膜计算与多目标约束处理的协同机制

### 6.1 四层约束处理链

Edge-FML实现了从预防到淘汰的完整约束处理链，体现了膜计算中多层次质量控制的思想：

**第一层——约束修复型变异（预防性）**：在子代生成阶段，通过安全等级强制提升（g4修复）、资源分配等比缩放（g1修复）和缓存溢出贪婪修复（g2修复），从源头预防约束违反。

**第二层——约束违反度计算**：评估每个解的四个约束违反度，计算总约束违反度CV = Σ max(0, g_j)，为目标优化和约束处理提供统一的量化指标。

**第三层——动态阈值过滤**：根据进化阶段动态调整的θ_T决定个体的生存资格，早期宽松、后期严格，实现从探索到利用的平滑过渡。

**第四层——环境选择溶解**：可行解按非支配等级和增强拥挤距离排序，不可行解按CV大小排序，确保约束满足始终优先于目标优化。

### 6.2 膜操作对目标优化的影响

不同膜操作对三个优化目标产生差异化影响：

| 膜操作 | 时延影响 | 能耗影响 | 安全风险影响 |
|--------|---------|---------|------------|
| DE交叉f_resource | 资源分配决定计算时间 | 频率³系数决定计算能耗 | 间接影响安全开销 |
| 二进制交叉x_offload | 本地vs边缘计算时间差异 | 传输能耗差异显著 | 卸载后暴露面扩大 |
| 安全修复z_security | 安全开销时间增加 | 安全能耗增加 | 直接降低风险值 |
| 二进制交叉y_cache | 缓存命中减少传输时间 | 减少重复传输能耗 | 间接影响 |
| 动态阈值θ_T | 约束严格时优先降时延 | 约束严格时优先降能耗 | 鼓励满足最小安全等级 |

### 6.3 约束优先偏序

在Edge-FML中，约束满足始终优先于目标优化。这一偏序关系体现在环境选择中：可行解无论目标值多差，都优先于不可行解被保留。当可行解不足时，从不可行解中按CV升序选择。这种设计确保了算法输出的最终解具有实际部署的可行性。

### 6.4 收敛性能保障机制

Edge-FML通过多种机制的协同作用保障算法的收敛性能：

- **动态阈值对数衰减**：实现从探索向利用的平滑过渡，避免早期过度约束导致搜索空间受限
- **DE/rand/1高探索性**：早期覆盖广阔搜索空间，跨越不可行区域
- **增强拥挤距离选择**：维持膜内Pareto前沿的多样性与均匀性，防止早熟收敛
- **集群内精英解交换**：每轮实现集群内膜间信息共享，加速局部收敛
- **联邦知识聚合**：每轮实现跨集群膜间信息传递，避免陷入局部最优陷阱
- **解适配器兼容性过滤**：确保外部膜知识在本地环境中的可行性
- **HV贡献精英选择**：在联邦聚合中选择对全局超体积贡献最大的精英解，优先保障收敛性

## 八、结论

本文提出的Edge-FML算法将膜计算范式与联邦学习框架深度融合，构建了一套面向边缘计算分布式多目标约束优化的完整解决方案。Edge-FML以三层联邦膜结构为核心架构，通过膜选择机制（约束支配+增强拥挤距离）、膜内进化操作（DE差分变异+三父代交叉+约束修复型变异）、动态膜溶解条件（θ_r(t) = θ_0 × timeFactor × loadFactor）和跨膜知识迁移（联邦聚合+解适配器兼容性过滤）等膜计算核心操作，实现了对时延、能耗和安全风险三个冲突目标的有效平衡，同时满足计算容量、缓存、截止时间和安全合规四个硬约束条件。膜计算操作的层次化、并行化和选择性渗透特性，使得Edge-FML能够在高度异构的边缘计算环境中，以较低的通信开销高效收敛到高质量的Pareto前沿。
