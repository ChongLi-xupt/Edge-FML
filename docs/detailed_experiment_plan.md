# Edge-FML 算法实验运行计划

## 1. 实验概述

本实验计划旨在全面评估 Edge-FML（Edge Federated Membrane Learning）算法的性能、设计合理性和比较优势。实验将分为三个主要部分：

1. **性能测试**：评估算法在不同规模数据集和区域数量下的性能表现
2. **消融实验**：验证算法各核心组件的必要性和贡献
3. **算法比较**：与现有联邦学习和分布式优化算法进行对比

## 2. 实验配置

### 2.1 基础配置

| 参数 | 取值 | 说明 |
|------|------|------|
| 联邦轮数（R_max） | 5 | 减少轮数以加快执行速度 |
| 每轮本地进化代数（M_local） | 20 | 减少本地进化代数以加快执行速度 |
| 精英解数量（M_elite） | 5 | 减少精英解数量以加快执行速度 |
| 种群大小（population_size） | 50 | 减少种群大小以加快执行速度 |
| 重复运行次数（repeat_runs） | 1 | 减少重复次数以加快执行速度 |
| 超体积参考点（metrics_ref） | [1000, 1000, 1000] | 用于超体积计算的参考点 |

### 2.2 数据集配置

| 数据集名称 | 规模 | 描述 |
|------------|------|------|
| benchmark_small.mat | 小 | 用于快速调试和测试 |
| benchmark_medium.mat | 中 | 用于标准性能测试 |
| benchmark_large.mat | 大 | 用于大规模性能测试 |
| benchmark_homogeneous.mat | 中 | 同质场景数据集 |
| benchmark_heterogeneous.mat | 中 | 异质场景数据集 |

## 3. 实验执行步骤

### 3.1 性能测试实验

**目标**：评估 Edge-FML 在不同规模下的性能表现，包括收敛速度、超体积、可行性率和多样性。

**执行步骤**：

1. 运行性能测试脚本：
   ```matlab
   run('experiments/performance_scaling/run_performance_experiments.m')
   ```

2. 性能测试配置：
   - 数据集：benchmark_small.mat
   - 区域数量：5
   - 场景类型：homogeneous

3. 预期结果：
   - 生成性能实验结果文件
   - 记录收敛曲线、超体积、可行性率和多样性指标

### 3.2 消融实验

**目标**：验证 Edge-FML 各核心组件的必要性和贡献，包括聚类机制、自适应阈值秘密共享、解决方案兼容性机制、本地优化增强和通信压缩。

**执行步骤**：

1. 运行消融实验脚本：
   ```matlab
   run('experiments/ablation_studies/run_ablation_experiments.m')
   ```

2. 消融实验配置：
   - 数据集：benchmark_medium.mat
   - 区域数量：30
   - 场景类型：heterogeneous
   - 消融变体：
     - full：完整 Edge-FML 实现
     - no_clustering：无聚类（扁平结构）
     - no_atsss：无自适应阈值 SSS
     - no_compat：无解决方案兼容性机制
     - no_local_enhance：无本地优化器增强
     - no_comm_compress：无通信压缩

3. 预期结果：
   - 生成各消融变体的实验结果
   - 对比各变体的性能指标，验证核心组件的贡献

### 3.3 算法比较实验

**目标**：将 Edge-FML 与现有联邦学习和分布式优化算法进行对比，包括中心化 MTDMS、独立 MTDMS、FedAvg-MOEAs 和原始 FML。

**执行步骤**：

1. 运行算法比较脚本：
   ```matlab
   run('experiments/algorithm_comparison/run_comparison_experiments.m')
   ```

2. 算法比较配置：
   - 数据集：benchmark_medium.mat, benchmark_heterogeneous.mat
   - 场景类型：moderate, heterogeneous
   - 比较算法：
     - Centralized-MTDMS：理想中心化优化
     - Independent-MTDMS：无协作基线
     - FedAvg-MOEAs：传统联邦平均
     - Original-FML：原始联邦膜学习
     - Edge-FML：提出的 Edge-FML

3. 预期结果：
   - 生成各算法的比较结果
   - 对比各算法的性能指标，验证 Edge-FML 的优势

## 4. 结果收集与分析

### 4.1 性能指标

- **超体积（Hypervolume）**：衡量 Pareto 前沿的质量和覆盖范围
- **可行性率（Feasibility Rate）**：可行解在种群中的比例
- **多样性指标（Diversity Metrics）**：衡量解的分布均匀性
- **收敛速度（Convergence Speed）**：算法收敛到最优解的速度
- **通信开销（Communication Overhead）**：算法的通信成本

### 4.2 结果文件格式

- 实验结果：MAT 文件，包含所有性能指标和中间结果
- 图表：PNG 和 FIG 格式，用于可视化分析
- 日志文件：TXT 格式，记录实验执行过程和关键信息

### 4.3 结果分析

1. **性能测试分析**：
   - 分析不同规模下的性能变化趋势
   - 评估算法的可扩展性
   - 识别性能瓶颈

2. **消融实验分析**：
   - 对比各消融变体的性能差异
   - 验证核心组件的贡献
   - 识别关键优化点

3. **算法比较分析**：
   - 对比 Edge-FML 与其他算法的性能优势
   - 分析不同场景下的表现差异
   - 验证算法设计的合理性

## 5. 实验执行顺序

1. 首先运行简单的性能测试，验证系统是否正常工作
2. 然后运行消融实验，验证算法各组件的贡献
3. 最后运行算法比较实验，验证算法的比较优势
4. 生成实验结果和图表
5. 编写实验分析报告

## 6. 故障排除

- **实验执行时间过长**：调整配置参数，减少联邦轮数、本地进化代数、种群大小或重复运行次数
- **内存不足**：减少种群大小或使用更小的数据集
- **算法崩溃**：检查日志文件，定位错误原因，修复代码
- **结果文件缺失**：检查文件路径和权限，确保结果文件能够正确保存
