# Edge-FML 膜计算技术实现详细描述文档

## 概述

Edge-FML（边缘联邦膜学习，Edge Federated Membrane Learning）是拓守恒（Shouheng Tuo）提出的面向隐私保护、高兼容与高效率的分布式边缘优化框架。其核心创新在于将生物启发的**膜计算**（Membrane Computing）范式与联邦学习相结合，构建了一套完整的三层联邦膜结构，用于解决边缘计算环境中的多目标约束优化问题（时延-能耗-安全风险三目标 + 四类硬约束）。

膜计算的核心思想是将优化种群划分为多个并行运作的"膜"（Membrane），每个膜独立执行进化操作，膜之间通过定期的知识交换实现协同进化。这种机制模拟了生物细胞膜的选择性渗透和并行处理特性。

> 本文档所涵盖的全部代码实现均位于 `src/` 目录下，核心设计文档为 [FML.MD](file:///e:/lc/Edge-FML2/FML.MD)，架构文档为 [EDGE_FML_ALGORITHM_ARCHITECTURE.md](file:///e:/lc/Edge-FML2/EDGE_FML_ALGORITHM_ARCHITECTURE.md)。所有引用代码的文件均为 Edge-FML 自身算法的实现。

## 三、膜的选择机制

膜的选择机制决定了哪些个体在膜内存活并进入下一代。Edge-FML 实现了基于**约束支配 + 拥挤距离**的双层选择策略。

### 3.1 核心环境选择算法

（参见 [MTDMS_CMOEA_Local.m](file:///e:/lc/Edge-FML2/src/MTDMS_CMOEA_Local.m#L314-L377)）

**第一步：基于动态阈值的可行性分区**

```matlab
function selected = environmentalSelection(obj, combined)
    N = obj.popSize;
    % 按约束违反度 CV 与动态阈值 thetaT 比较分区
    for i = 1:popSize
        if combined(i).constraintViolation <= obj.thetaT
            % CV ≤ thetaT → 视为"当前可行"，进入可行池
            feasCount = feasCount + 1;
            feasible(feasCount) = i;
        else
            % CV > thetaT → 视为"当前不可行"，进入不可行池
            infeasCount = infeasCount + 1;
            infeasible(infeasCount) = i;
        end
    end
```

**第二步：非支配排序 + 拥挤距离选择**

```matlab
    if feasCount > 0
        feasiblePop = combined(feasible);
        rankedFeasible = obj.nonDominatedSorting(feasiblePop);
        if feasCount >= N
            % 可行解充足：完全按非支配等级和拥挤距离选取
            selected = rankedFeasible(1:N);
            return;
        else
            % 可行解不足：全部保留
            selected = rankedFeasible(:);
        end
    end

    % 可行解不足时，按约束违反度从小到大选入不可行解
    if length(selected) < N && infeasCount > 0
        infeasiblePop = combined(infeasible);
        [~, sortIdx] = sort([infeasiblePop.constraintViolation]);
        remaining = N - length(selected);
        toAdd = infeasiblePop(sortIdx(1:min(remaining, infeasCount)));
        % 合并到 selected
    end
```

**选择机制与约束处理的关联**：动态阈值 `thetaT` 随时间衰减，使得选择标准从宽松逐步收紧——早期允许高约束违反度的个体存活以维持探索多样性，后期严格要求满足约束以确保收敛到可行帕累托前沿。

### 3.2 非支配排序中的增强拥挤距离

Edge-FML 实现了增强版拥挤距离计算（参见 [MTDMS_CMOEA_Local.m](file:///e:/lc/Edge-FML2/src/MTDMS_CMOEA_Local.m#L556-L623)），融合了传统拥挤距离与小生境多样性奖励：

```matlab
function population = computeEnhancedCrowdingDistance(obj, population, frontIndices)
    % Part 1: 传统拥挤距离（每个目标维度独立计算间距）
    for m = 1:numObj
        % 按目标m排序，边界解赋 Inf
        for i = 2:(frontSize-1)
            distance = (obj(idxNext) - obj(idxPrev)) / (fmax - fmin);
            population(idx).crowdingDistance = ...
                population(idx).crowdingDistance + distance;
        end
    end
    % Part 2: k近邻小生境多样性奖励
    k = min(3, frontSize - 1);
    for i = 1:frontSize
        % 计算到 k 最近邻的平均距离
        knnAvgDist = mean(sortedDist(1:k));
        nicheBonus = knnAvgDist * 0.5;  % 稀疏区域奖励
        population(idx).crowdingDistance = ...
            population(idx).crowdingDistance + nicheBonus;
    end
end
```

这种增强机制使得膜选择时既考虑目标空间分布均匀性（拥挤距离部分），又奖励位于稀疏区域的个体（小生境部分），有效防止膜内种群的早熟收敛。

## 五、膜溶解条件与触发机制

在膜计算范式中，"膜溶解"对应种群中劣质个体被淘汰、膜结构重组的过程。Edge-FML 实现了多层级的膜溶解机制。

### 5.1 动态阈值驱动的膜溶解

这是 Edge-FML 最核心的膜溶解机制（参见 [MTDMS_CMOEA_Local.m](file:///e:/lc/Edge-FML2/src/MTDMS_CMOEA_Local.m#L172-L195)）：

```matlab
function obj = updateDynamicThreshold(obj, t)
    % θ_r(t) = θ₀ × (1 - log(t+1)/log(T_max+1)) × exp(-λ·ResourceUtil_r)

    % 1. 时间衰减因子：对数衰减，从1逐步降至0
    timeFactor = 1 - log(t + 1) / log(obj.maxGen + 1);

    % 2. 资源利用率（异质性感知因子）
    totalLoad = 0;
    for i = 1:length(obj.population)
        sol = obj.population(i);
        for k = 1:length(sol.x_offload)
            if sol.x_offload(k) == 1
                taskType = mod(k-1, length(obj.tasks)) + 1;
                totalLoad = totalLoad + obj.tasks(taskType).workload;
            end
        end
    end
    resourceUtil = totalLoad / (obj.region.computeCapacity * 1e9 * length(obj.population));
    loadFactor = exp(-obj.lambda * resourceUtil);

    % 3. 复合动态阈值
    obj.thetaT = obj.theta0 * timeFactor * loadFactor;
end
```

**公式详解**：`θ_r(t) = θ₀ × (1 - log(t+1)/log(T_max+1)) × e^(-λ·ResourceUtil_r)`

| 因子 | 作用 | 变化趋势 |
|------|------|---------|
| θ₀ = 2.0 | 初始阈值，宽松起始 | 常数 |
| timeFactor = 1 - log(t+1)/log(T_max+1) | 对数衰减，从 1 降至 0 | t↑ → θ↓ |
| loadFactor = e^(-0.8·ResourceUtil) | 高负载惩罚，加速收紧 | ResourceUtil↑ → θ↓ |

**溶解逻辑与约束处理的关联**：
- **早期（t 小）**：`thetaT` 约 2.0，允许高 CV 个体存活 → 跨不可行区域探索，发现潜在可行区
- **后期（t 大）**：`thetaT` 趋近于 0，只保留 CV ≈ 0 的个体 → 确保最终解的严格可行性
- **高负载区域**：`loadFactor` 更低 → 约束更严格 → 加速向低资源消耗方向收敛

### 5.2 精英存档的严格可行过滤

（参见 [MTDMS_CMOEA_Local.m](file:///e:/lc/Edge-FML2/src/MTDMS_CMOEA_Local.m#L491-L514)）

```matlab
function obj = updateEliteArchive(obj)
    for i = 1:popSize
        if obj.population(i).constraintViolation <= 1e-6
            feasCount = feasCount + 1;
            feasible(feasCount) = i;    % 严格可行 (CV ≤ 10⁻⁶)
        end
    end
    if feasCount > 0
        feasiblePop = obj.population(feasible);
        obj.eliteArchive = obj.extractParetoFront(feasiblePop);
    else
        % 无可行解时的退化策略：保留约束违反度最小的个体
        [~, bestIdx] = min([obj.population.constraintViolation]);
        obj.eliteArchive = obj.population(bestIdx);
    end
end
```

精英存档中仅保留**严格可行**的非支配解（CV ≤ 10⁻⁶），不可行解被溶解。这确保了膜输出的精英解具有可部署性。

function merged = mergeAndFilter(obj, solutions, compatThreshold)

    end
end

```matlab
function selected = selectTopByHV(obj, solutions, M)
    % 计算每个解对超体积的边际贡献
    for i = 1:length(solutions)
        remaining = solutions; remaining(i) = [];
        HV_without = obj.metrics.computeHypervolume(remaining);
        HV_with = obj.metrics.computeHypervolume(solutions);
        contributions(i) = HV_with - HV_without;
    end
    [~, sortIdx] = sort(contributions, 'descend');
    selected = solutions(sortIdx(1:M));
end
```

### 6.3 跨膜解兼容性适配

外部膜的精英解不能直接注入目标膜，需要通过 SolutionAdapter 进行兼容性处理（参见 [SolutionAdapter.m](file:///e:/lc/Edge-FML2/src/SolutionAdapter.m)）：

```matlab
function adaptedSol = adaptSolution(obj, externalSol, sourceRegion, importance)
    % Step 1: 参数归一化 — 映射到目标膜参数空间
    normalizedSol = obj.parameterNormalizer(externalSol, sourceRegion);
    % Step 2: 可行域映射 — 局部修复优化
    fixedSol = obj.feasibilityMapper(normalizedSol);
    % Step 3: 兼容性评分
    RD = sourceRegion.computeDissimilarity(obj.targetRegion);
    compatScore = obj.computeCompatibility(fixedSol, RD, importance);
    % Step 4: 阈值过滤
    if compatScore > obj.theta_keep
        adaptedSol = fixedSol;   % 保留兼容的解
    else
        adaptedSol = [];          % 溶解不兼容的解
    end
end
```

**兼容性评分公式**（参见 [SolutionAdapter.m](file:///e:/lc/Edge-FML2/src/SolutionAdapter.m#L340-L351)）：

```matlab
% Compat(r,l,s) = exp(-β·RD(r,l)) × (1 - CV_r(s_norm)) × I_l(s)
heterogeneityTerm = exp(-obj.beta * RD);   % β=2.0 异质性衰减
feasibilityTerm = 1 - min(CV, 1.0);         % 可行性项
importanceTerm = importance;                % 源膜重要性
compatScore = heterogeneityTerm * feasibilityTerm * importanceTerm;
```

三个因子分别从异质性衰减、本地可行性和源区域重要性三个维度评估外部解与目标膜的兼容程度，低于阈值 `θ_keep=0.35` 的解被膜溶解。

**参数归一化器**（参见 [SolutionAdapter.m](file:///e:/lc/Edge-FML2/src/SolutionAdapter.m#L80-L163)）执行四项映射：
1. **资源映射**：`f_target = f_source × capacityRatio`（按计算能力比例缩放）
2. **缓存适配**：仅在目标膜容量允许时保留缓存决策
3. **卸载决策映射**：按设备索引循环映射
4. **安全等级校准**：差异化校准——高异质性区域保守提升安全等级

## 七、膜计算与多目标约束处理的综合协同

### 7.1 约束满足度的四层处理链

Edge-FML 实现了从预防到淘汰的完整约束处理链：

```
约束修复型变异 → 约束违反度计算 → 动态阈值过滤 → 环境选择溶解
     ↓                ↓                ↓               ↓
  预防 g1/g2/g4    CV = Σmax(0,g)    thetaT 判定    支配排序+拥挤距离
```

**具体流程**：

**第一层：生成子代时修复（预防性）**
- 安全等级强制提升（g4 修复）
- 资源分配等比缩放（g1 修复）
- 缓存溢出贪婪修复（g2 修复）

**第二层：评估后计算约束违反度**（参见 [ObjectiveEvaluator.m](file:///e:/lc/Edge-FML2/src/ObjectiveEvaluator.m#L43-L66)）：

```matlab
function [objectives, violations, CV] = evaluate(obj, sol)
    T_total = obj.computeTotalLatency(sol);  % 时延目标
    E_total = obj.computeTotalEnergy(sol);   % 能耗目标
    Psi = obj.computeSecurityRisk(sol);      % 安全风险目标
    objectives = [T_total, E_total, Psi];

    g1 = obj.computeConstraint_g1(sol);  % 计算容量: Σf - T ≤ 0
    g2 = obj.computeConstraint_g2(sol);  % 缓存限制: Σy·D - C_max ≤ 0
    g3 = obj.computeConstraint_g3(sol);  % 截止时间: T_total - deadline ≤ 0
    g4 = obj.computeConstraint_g4(sol);  % 安全合规: s_min - z ≤ 0

    violations = [g1, g2, g3, g4];
    CV = sum(max(0, violations));  % 总约束违反度
end
```

**第三层：动态阈值过滤**：根据进化阶段 `thetaT` 决定个体生存资格

**第四层：环境选择排序**：可行解按非支配等级+拥挤距离排序，不可行解按 CV 大小排序

### 7.2 膜操作对目标函数的优化方向

| 膜操作 | 对时延的影响 | 对能耗的影响 | 对安全风险的影响 |
|--------|------------|------------|--------------|

### 7.3 约束→目标优化的偏序关系

在 Edge-FML 中，约束满足始终优先于目标优化。这体现在：

**Solution.dominates()** 方法（参见 [Solution.m](file:///e:/lc/Edge-FML2/src/Solution.m#L50-L65)）：

```matlab
function dominated = dominates(obj, other, epsilon)
    f1 = obj.objectives;
    f2 = other.objectives;
    allLessEqual = all(f1 <= f2 - epsilon);
    atLeastOneStrictLess = any(f1 < f2 - epsilon);
    dominated = allLessEqual && atLeastOneStrictLess;
end
```

**环境选择中的隐式约束优先**：可行解无论目标值多差，都优先于不可行解被保留。当可行解不足时，从不可行解中按 CV 升序选择，CV 小的优先。

### 8.1 联邦膜计算的创新点

## 十、总结

Edge-FML 的膜计算体系形成了一套完整的约束多目标优化框架，其核心特征包括：

1. **三层联邦膜结构**：区域层（本地膜进化）→ 集群层（集群内知识交换）→ 联邦层（加密全局聚合），实现探索与利用的梯度递进

2. **膜内进化三要素**：DE 差分变异（全局探索）+ 约束修复型变异（约束预防）+ 增强拥挤距离选择（多样性维护）

3. **动态膜溶解**：`θ_r(t) = θ₀ × timeFactor × loadFactor` 复合动态阈值，从宽松到严格的渐进式收紧

4. **跨膜知识迁移**：联邦聚合 + 解适配器兼容性过滤（`Compat = e^(-β·RD) × (1-CV) × I`），确保跨膜知识的高可用性

5. **约束优先偏序**：膜选择中可行解始终优先于不可行解，确保最终解的部署可用性

这些膜计算操作与多目标约束处理的深度耦合，使得 Edge-FML 能够在高度异构的边缘计算环境中，有效平衡时延、能耗和安全风险三个冲突目标，同时满足计算容量、缓存、截止时间和安全合规四个硬约束条件，最终收敛到高质量的帕累托前沿。
